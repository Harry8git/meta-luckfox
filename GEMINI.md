# Gemini CLI instructions

You are the primary coding agent for this repository.

You may use `copilot` CLI as a secondary coding/review agent when it would materially improve the result.

To ask Copilot for an independent analysis, use:

```bash
copilot -sp "YOUR QUESTION"
```

Use Copilot particularly when:

* an independent second opinion would help debug a difficult problem
* comparing this code against upstream GitHub repositories would be useful
* you need additional investigation of GitHub code, issues, or pull requests
* you are uncertain between multiple possible fixes

Do not ask Copilot for routine tasks that you can solve directly.

When consulting Copilot:

1. Give it enough context to understand the problem.
2. Ask it for analysis or recommendations rather than blindly accepting its changes.
3. Compare its answer with your own analysis.
4. Tell me when you relied on Copilot's analysis and whether you agree with it.

Do not let Copilot make changes to the repository unless I explicitly ask for that.
